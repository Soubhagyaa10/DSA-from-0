# DSA in C++
This repository contains my journey of learning Data Structures and
Algorithms using C++.

## Goals
- Build strong problem-solving skills
- Understand DSA concepts from fundamentals
- Practice writing solutions independently
- Improve time and space complexity analysis
- Prepare for coding interviews and placements

## Topics
- Programming Fundamentals
- Loops and Functions
- Arrays
- Strings
- Searching
- Sorting
- Recursion
- Linked Lists
- Stacks and Queues
- Trees
- Graphs
- Dynamic Programming

## Approach
For each problem, I try to follow:
Problem → Example → Manual Solution → Pseudocode → Code → Dry Run → Complexity
This repository documents my progress and learning process.
